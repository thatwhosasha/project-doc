# Словарь

## Участники и роли

| Термин | Определение |
|---|---|
| Пользователь | Зарегистрированный слушатель, который ищет и воспроизводит треки, ставит лайки и управляет плейлистами. |
| Артист | Исполнитель или группа, зарегистрированные для загрузки и публикации музыки. |
| Модератор | Участник, проверяющий музыкальные публикации и принимающий решение об их одобрении или отклонении. |
| Рекламодатель | Участник, создающий кампании, загружающий рекламные материалы и выбирающий целевую аудиторию. |

## Музыкальный контент и действия

| Термин | Определение |
|---|---|
| Трек | Отдельная музыкальная запись, доступная в каталоге после публикации. |
| Альбом | Музыкальная публикация артиста, объединяющая один или несколько треков. |
| Плейлист | Созданный пользователем список треков, который пользователь может открывать и изменять. |
| Избранное | Личная коллекция треков пользователя, добавленных им с помощью лайка; пользователь может просматривать её и удалять из неё треки. |
| Лайк | Отметка пользователя на исполнителя. Установка лайка добавляет исполнителя в избранное |
| Прослушивание | Воспроизведение трека пользователем через сервис. Правило учёта прослушивания в статистике исходными материалами не определено. |
| Модерация | Проверка загруженного трека или альбома перед публикацией и решение об одобрении либо отклонении. |
| Оценка | Числовая или иная рейтинговая оценка трека; в текущий объём проекта не входит. Лайк не является оценкой. |

## Реклама и аналитика

| Термин | Определение |
|---|---|
| Кампания | Созданный рекламодателем набор параметров и материалов для размещения рекламы. |
| Рекламный материал | Контент рекламодателя для размещения в рамках кампании; перед публикацией проходит проверку. |
| Целевая аудитория | Группа пользователей, на которую рекламодатель настраивает кампанию. |
| Статистика | Агрегированные показатели прослушиваний, работы платформы или рекламной кампании. Лайки не включены в статистику. |

## Технические и проектные термины

| Термин | Определение |
|---|---|
| Аккаунт | Учётная запись, созданная при регистрации и используемая для входа в сервис. |
| Аудиофайл | Файл с музыкальной записью, загружаемый артистом и используемый для воспроизведения после одобрения. |
| Веб-приложение | Сервис, доступный через веб-браузер без установки отдельного мобильного приложения. |
| Браузерный движок | Компонент браузера для отображения и исполнения веб-страниц; |
| Доступность сервиса | Доля времени расчётного периода, в течение которой основные пользовательские функции работоспособны. |
| RTO | Максимально допустимое время восстановления сервиса после отказа. |
| RPO | Максимально допустимый период утраченных изменений данных при восстановлении из резервной копии. |
| Релиз | Этап поставки функций продукта. На User Story Map указаны MVP, релиз 2 и релиз 3. |

**Разграничение терминов:** лайк — отметка пользователя; избранное — коллекция треков, добавленных с помощью этой отметки. Лайки не учитываются как прослушивания и не образуют отдельный показатель статистики.
